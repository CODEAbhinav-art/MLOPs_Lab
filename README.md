# MLOps Lab Assignment 1

## Objective

This project was created as part of the MLOps Lab Assignment 1.
The objective is to understand the fundamentals of MLOps and explore
the MLflow experiment tracking platform.

## Project Structure

- data/ – Dataset files
- notebooks/ – Jupyter notebooks
- src/ – Source code
- models/ – Machine learning models
- reports/ – Lab reports and documentation
- configs/ – Configuration files
- requirements.txt – Python dependencies
- .gitignore – Git ignored files

## Topics Covered

- Introduction to MLOps
- ML Lifecycle
- DevOps vs DataOps vs MLOps
- CI, CD and CT
- Model Monitoring
- Model Registry
- MLflow Experiment Tracking
